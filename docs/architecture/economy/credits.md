# 架构设计：积分内核（发行、兑付、恒等式与储备）

> 模板：产品目标 → 现状 → 差距 → 目标设计 → 迁移路径 → 验收。对应产品文档：[../../product/economy/credits.md](../../product/economy/credits.md)（定稿）。本篇是经济内核（product/todo #8）的主体，里程碑一前置。

## 一、产品目标（来自 product/economy/credits.md）

1. 积分 = 组织对持券人的资源兑付承诺：记名、唯一序列号、只在发行组织兑付、**兑付即销毁**；定点刻度（存储运算一律刻度整数、禁浮点）；
2. **发行必须依据经决议授权的发行策略**：策略立改废走公示延迟决议；**策略内发行内核按规则确定性执行**（触发事件须来自存证链 / 事务日志的可验证记录）；裁量发行逐次决议；无私钥直接发行接口；不得按出资 / 职位 / 关系发行；
3. 序列号状态机（issued→held→locked→redeemed/burned）+ append-only 流水 + **恒等式（发行总量 = 已销毁 + 在外流通）随时可核验**；销毁必须被见证（销毁日志）；
4. **兑付端最小机制**：兑付单状态机（proposed→accepted→delivered→burned + rejected / timeout / disputed 挂起等裁决凭证，内核不裁决）；三类供给只在交付确认时机不同；最小供给声明（结构化 / 版本化 / 留痕，内核不核实真伪）；交付佐证形式归插件；
5. 两类积分分立（贡献积分 vs 权益凭证，不混账）；规则三级公开 + 版本化（变更走自声明程序 + 公示时间锁，存量不溯及）；
6. 特殊生命周期：退社（按加入时已公开规则，禁止临场剥夺；贡献历史永久解耦）、主体消亡无继承、时效原语、红冲（同等授权的追加事务）、兑付紧张（确定性排队、不得插队）；
7. 组织内分配：不可分割储备（无按份私分出口）、发行分流（公共扣除）、治理岗位经济约束；**成员出资不设内核对象**（product/economy/credits 定稿口径；product/roadmap §五 v2 残留表述已于 2026-09-08 清理对齐）；长期荣誉 = 插件视图。

## 四、目标设计

### 4.1 线形与状态机（`economy/types.rs`）

```jsonc
// 积分批次
{ "batchId": "<64hex>", "orgId": "org_<…>", "rulesRef": { "pkgHash": "<64hex>", "version": 3 },
  "scale": 3,                      // 最小刻度（小数位），规则包声明
  "authRef": "<evi:resolution 锚>", // 发行策略的决议授权锚
  "triggerRef": "<触发事件存证锚>", // 触发发行的可验证记录（评定过程可核验）
  "expiresAt": null,               // 批次时效（母稿 §2 口径：批次带 expires_at）
  "createdAt": 1720000000000 }
// 序列号条目（记名持有）
{ "serial": "<batchId>:<u64>", "holder": "<64hex>", "amount": 12500, // 刻度整数（=12.500）
  "state": "issued|held|locked|burned|expired" }
// 销毁日志条目（见证）
{ "serial": "…", "amount": 12500, "burnedAt": "…", "redemptionId": "<64hex>", "sig": "…" }
```

- **状态机不可回退**（宪章层）：迁移只许 issued→held→locked→burned（及 locked→held 回滚）；**到期确定性迁移**：批次 `expiresAt` 到达（时间以存证链为准）→ 该批次未销毁序列号迁移 `expired`（不再计入"在外流通"，与母稿 :166 口径一致——设效期则到期脱债，不设 = 组织承担永久负债）；
- **恒等式**（按**批次族类型内**分别成立——贡献积分 / 权益凭证不混账，product/credits 两类分立）：`Σ发行(批次族) = Σ销毁(销毁日志) + Σ在外(state ∉ {burned, expired})`——确定性内核函数；**复算视图锚点**：以指定存证锚时刻的流水视图为准复算（无锚点时各节点视图互异、无法判伪——"任何成员随时可核验"的语义落点 = 任取一个共同锚时刻复算必一致）；
- **流水的存证拓扑**（与 affair-model §4.1 同裁定）：流水与批次 / 序列号条目是**组织同步数据**（orgsync 键域复制，全员可得）；各节点在合入流水时**确定性自写**存证条目（同内容同字节），锚记录经 orgsync 全员流动——"入组织存证链"的承载 = 锚流动 + 条目确定性可复算重写，不引入组织级复制链新概念。

### 4.2 发行：策略触发求值（`issuance.rs`）

1. **发行策略**（组织级对象，立改废走公示延迟 ruleChange，授权锚 = `evi:resolution`）：`{ rulesRef, triggers: [{ event: "affair.adopted" | "affair.closed" | …, filter: <声明式>, amount: <声明式表达式> }], discretionaryAllowed: bool }`；
2. **策略内发行（内核确定性执行）**：监听事务日志事件（PR 合并 / 需求被采纳等——affair 操作日志本就存证）→ 匹配 trigger → 求值 amount（声明式，policy 引擎同族求值）→ 落批次与序列号——**无决议动作、零治理开销**；
3. **裁量发行**：逐次走**普通决议事务**（一次性发行决议，授权锚 = `evi:resolution`）——非 ruleChange（规则修订链只管策略立改废）；
4. **形式合规校验**（母稿 §9 口径）：内核只校验授权锚有效、触发事件真实（存证回查）、表达式求值确定——不判断贡献值多少；不得按出资 / 职位 / 关系发行（trigger 过滤条件静态禁止这三类字段）；
5. **发行分流**：一笔发行按规则包声明比例自动拆入个人账户与公共储备池（公共扣除原语，比例与用途政策层）。

### 4.3 兑付端（`redemption.rs` + `supply.rs`）

- **兑付单状态机**（`locked` 原语由本篇序列号状态机定义，inter-org 后段复用本篇）：`proposed（held→locked）→ accepted → delivered → burned（销毁日志）`；异常：`rejected / timeout → 解锁回 held`；`disputed → 维持锁定挂起，等组织规则认可的裁决凭证`（内核不裁决——只有"挂起"原语）；
- **三类供给的确认时机**：实物（领取 / 签收）、服务（完成时点，预约即锁）、资源使用权（时段结束）；
- **交付佐证**：佐证形式与"什么佐证触发什么状态迁移"由插件定义（catalog 交付佐证插件），内核只按插件提交的佐证记录执行状态迁移（佐证哈希入兑付单）；
- **最小供给声明**：`{ supplyV, items: [{ name, price, capacity }], updatedAt, sig }`——结构化 / 版本化 / 留痕；它是"在外积分 vs 可兑资源"比值的分母（健康度确定性计算）；内核不核实真伪；
- **兑付紧张**：可兑 < 在外时按事先公开规则触发限额 / 排队 / 暂停新增发行；排队按申请序号确定（先到先得），任何身份不得插队；健康度标红。

### 4.4 生命周期杂项

- **红冲**：同等授权的追加事务（引用并抵消指定批次）；恒等式记账方式：红冲记录**抵减发行侧**（`Σ发行` 扣除红冲额），在外与销毁两侧不动；已销毁部分确实追不回的计入组织损失、**不得摊派**；
- **时效**：批次 `expiresAt` 原语（是否设效期政策层；不设 = 组织承担永久负债）；到期迁移见 §4.1 状态机；
- **退社 / 消亡**：存量按加入时已公开规则版本处置（规则版本化、存量不溯及）；无继承（人身性、不可转让）；贡献历史永久解耦（事实层，插件做档案视图）；
- **不可分割储备**：`reserve` 账户结构——入账接口开放、**无按份私分出口**（结构封死）；组织解散时余额只许转入组织程序指定的受让共同体（受让方由组织程序决定；**内核不提供"同类组织"判定**——"同类"无确定性判据，判定归治理档，内核只执行转账）；
- **两类积分分立**：贡献积分与权益凭证（预付型）各自独立批次族与账户呈现，不混账、不设找赎套现；
- **治理岗位经济约束**（报酬倍数上限等）：归规则包 / 章程声明，**内核无机制**（如实标注，不设内核对象）。

### 4.5 定点数（`fixed.rs`）

u128 刻度整数；显示层定点小数（刻度由规则包声明，模板建议 3–6 位）；汇率整数比、连乘；**只在最终落账抹零一次**，取整方向规则包声明（内核只按声明确定性取整，**方向声明即零头处理**——声明向下即零头免收不挂账，防 salami 汇聚）；销毁额 = 应收额同一离散值（分布式一致性前提）。

## 五、迁移路径

绿地。落地顺序：`fixed` + `types` → `issuance`（含分流）→ `redemption`（兑付单）→ `supply` / `reserve` → 生命周期杂项 → 恒等式复算工具（供独立审计）。自举社区（catalog 积分规则包·自举版）为首个真实用户。

## 六、验收

- **向量**：批次 / 序列号 / 兑付单线形逐字节；状态机全迁移真值表（含非法回退必败）；恒等式用例（发行 = 销毁 + 在外，含红冲联动）；定点数（刻度换算、连乘、末步取整方向、同离散值、salami 防护）；分流比例；
- **单测**：trigger 匹配与金额求值、形式合规校验（无授权锚 / 假触发必败）、出资/职位/关系字段静态禁止、兑付单三异常分支、disputed 挂起与裁决凭证解锁、排队序号确定性；
- **集成**：自举场景 e2e——规则包启用（决议）→ PR 合并 → 自动发行 → 成员兑付资源 → 销毁见证 → 恒等式审计通过 → 导出包给第三方复算；
- **回归**：affair / evidence / policy 既有用例全绿（经济层只读它们的事件与锚，不改语义）。
