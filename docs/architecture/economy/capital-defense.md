# 架构设计：资本防线、风险有界化与出清

> 模板：产品目标 → 现状 → 差距 → 目标设计 → 迁移路径 → 验收。对应产品文档：[../../product/economy/capital-defense.md](../../product/economy/capital-defense.md)（定稿）。后段设计（随 inter-org 之后）。

## 一、产品目标（来自 product/economy/capital-defense.md）

1. 11 条资本防线按三档成色落地：【结构】内核不设接口、【证据】确定性产出可复算指标但不裁决、【治理】承认技术无能为力（不伪装成技术保证）；
2. 风险有界化六机制：双边净应收硬上限、全网敞口透明、净额真实平仓、枢纽约束（可选阈值拦截原语）、**有序出清**（内核提供状态冻结 / 恒等式 / pro-rata 确定性计算 / 全程存证；启动与方案归组织程序）、损失自担永不兜底；
3. 防信任慢性退潮：健康度确定性指标（在外 / 可兑比、净应付趋势、平仓及时率、授信集中度、枢纽度），内核只输出不决策；
4. 相关性风险：成员 / 控制人重叠度确定性计算【证据】，是否合并视为主体归受理组织【治理】。

## 四、目标设计

### 4.1 组织健康度指标（G1，证据档）

`economy/health.rs`（纯逻辑）：输入 = 发行 / 销毁 / 在外流水 + 供给声明 + 往来账 + 平仓记录，输出确定性指标（在外 / 可兑比、净应付趋势、平仓及时率、授信集中度、枢纽度）——**任何节点复算结果一致**（与 affair 健康信号同纪律）；呈现方式由客户端 / 插件竞争，内核只输出指标、不做"收紧 / 放行"决定。

**全网敞口透明（G5，机制 2 的落点）**：发行方将健康度指标结果（在外积分 / 授信总和 / 已占用净额 / 平仓历史摘要）作为**签名披露物**周期性发布——载体复用公共目录面（org-card 扩展字段 / indexer 聚合，public-topics 篇 §4.1 同族）；任何节点拿到披露物后凭同一流水视图**确定性复算核对**（指标是复算函数，披露只是触发）——不披露的发行方 = 无人签约（自担孤立，inter-org §4.4 同口径）。协议侧只定义披露物线形与复算函数，聚合与呈现归 indexer。

### 4.2 有序出清原语（G2）

`economy/winddown.rs`：

1. **状态冻结**：出清启动（组织程序决定，启动决议以 `evi:resolution` 锚进入内核感知）→ 内核将该组织积分状态机与往来账冻结（只读），冻结点存证；
2. **资产盘点**：恒等式给出冻结点的在外总量；可兑资源清单 = **组织程序盘点结果（决议锚定）** + 储备账户余额——内核不核实盘点真伪，只对盘点结果做确定性计算（product 口径）；
3. **pro-rata 计算**：按"可兑资源 / 在外总量"比例计算每序列号可兑付额（定点数末步取整，方向按规则包声明）——确定性、可复算；
4. **全程存证**：冻结 / 盘点 / 比例 / 兑付逐条入存证链（"把跑路变成可被全见证的清算"由组织写入创世章程——章程层，非内核义务）；
5. **永不兜底**：坏账由自主授信的受理组织承担；内核无"社会化分摊 / 平台兜底 / 增量填旧坑"任何操作类型（结构封死）。

### 4.3 枢纽与重叠度（G3/G4）

- **枢纽度**：协议图连接度 / 占比确定性计算；提供**可选阈值拦截原语**（组织自声明阈值，超过即暂停新授信——原语在内核，阈值与启用归组织）；
- **重叠度**：两组织成员集 / 控制人（管理员集）重叠比例确定性计算【证据】；合并视为风险主体与否是受理组织的授信决定【治理】，内核不代合并；
- **邻域汇率偏离**：同一资源在相邻双边协议上的汇率偏离度确定性计算（输入 = 协议图 rate 整数比，纯 `fixed.rs` 运算）——指标输出，告警与处置归客户端 / 组织（防线 #11 的另一半落点）。

## 五、迁移路径

绿地 + 后段（随 inter-org 之后）。落地顺序：health → winddown → 枢纽 / 重叠度。其中**不依赖往来账的指标（在外 / 可兑比）单组织期即可用**，可随 credits 批（A36）先行落地；依赖往来账的指标与 winddown 随 A39。

## 六、验收

- **向量**：健康度指标确定性（固定流水 → 固定指标值）；pro-rata 计算（含取整与方向）；冻结 / 盘点 / 兑付存证序列；
- **单测**：冻结后写入拒绝、兜底类操作不存在（负向）、阈值拦截启停、重叠度计算；
- **集成**：组织出清 e2e——违约 → 冻结 → 盘点 → pro-rata 兑付 → 全见证存证可经导出包独立核验；
- **回归**：credits / inter-org 全部用例（防线证明与负向测试同步跑）。
