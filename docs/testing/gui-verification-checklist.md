# GUI 人工验证清单（阶段③收尾，删除 TS 主进程前必过）

> 本文档从 [testing.md](testing.md) 拆分出来，独立覆盖 GUI 人工验收。

逐项在新 Tauri PC 壳上人工过一遍；全部通过后才删除旧 TS 主进程。

**单机多开（无需多台电脑）**：`npm run tauri dev N` 一条命令起 N 个实例
（`npm run tauri dev` 仍是单实例，行为不变）——实例 1 拉起 vite dev server，
其余实例经 `-c` 覆盖跳过 beforeDevCommand 复用同一 dev server；每实例独立
数据目录 `app/.dev-data/instance-<i>`（已 gitignore；sled 单目录独占必须隔离，
监听端口自动避让）；Ctrl+C 一次全部退出（同进程组收信号，包装器 10s 宽限后
兜底强杀）。各实例各自注册身份、互扫名片即可走通加好友/聊天/组织邀请全流程；
想清空重来删掉 `app/.dev-data/` 即可。

内核层全链路另有自动化 e2e：`cargo build --example e2e_node && python3 scripts/e2e/run_all.py`
（stdio 驱动真实 kernel 实例 + 场景断言，见 [rust-unit-integration](rust-unit-integration.md)），GUI 走查只需关注前端显示问题。
