# 与法币世界的关系：正常经营，但不被收编

> 状态：定稿 ｜ 分册：第四层 · 经济
>
> 母稿：《共同体经济系统设计.md》v0.10 §5。

## 一句话

Spark **不隔离法币、不搞封闭乌托邦**：组织可以登记为合法市场主体、对外销售产品服务、收取法币、依法纳税；但要守住四道闸门，防止积分在一代人之内被法币收编回普通"商家积分"，并把对外盈余导向互惠板块的扩大再生产而非资本积累。

## 不隔离：组织可以对外正常经营

互惠经济必须有真实生产力与对外交换才可持续。组织可登记为合作社、社会企业、民非、集体企业等合法形态，对外经营、依法纳税。

## 防收编四闸门（缺一道，积分即被收编）

1. **不开对私兑现通道**：组织可以收法币，但个人积分绝不可兑成法币；
2. **不挂汇率**：积分兑资源的比例由集体按劳动评定，产品对外的法币售价另立一套账，两者之间**不公布、不承诺换算关系**；
3. **法币收入归集体、按章程支配**：经营账与积分账分立，禁止按出资分润；
4. **积分价值首先落在网络内真实资源上**：成员的主要收益来自网络内确实存在、且外部买不到或更贵的东西（互助照护、公共资源、托育养老、协作生产），而不是间接变现。

**四道闸门的成色不一样，如实标注**：闸门 1 是**结构封死**（内核没有对私兑现接口，物理上做不到）；闸门 2、3、4 的对象是**系统外法币与组织纪律**，软件没有任何强制力——它们的保障是"系统内积分侧流水全可核验 + 系统外法账用插件记账形成可对照留痕 + 章程与法律 + 成员监督"。**对外材料不得宣称"软件能防止法币私分、能保证顺差用于扩大再生产"**——Spark 封死的是积分侧的资本化通道；系统外的钱怎么流动，封不死，也不假装封得住。

## "顺差"的正确性质：互惠板块的扩大再生产

网络对外部出超换来的法币，只允许三个去向：

1. **购回网络内造不出的使用价值**（W—G—W，花掉即退出）；
2. **充实共同储备与互助保险**（抗风险，不对外食利）；
3. **孵化新组织、添置联合占有的公共生产资料**（让互惠板块变大）。

**这三个去向是组织章程纪律**：对象同样是系统外法币——Spark 提供可对照的留痕，执行靠组织程序与成员监督。

目标**不是消灭法币**（法币需求由税收等国家制度刚性支撑，平行货币替代不了，也不追求替代），而是：**成员为了生存、不得不向外部资本逻辑出卖劳动的比例持续下降。**

## 资本结构在 Spark 上的位置：三层分述

现实中的股份制、出资、分红在 Spark 上各有确定的位置，既不假装不存在，也不提供增殖通道：

- **信息面——可映射**：股东名册、股权比例、分红计算、财务报表，这些是数据与计算，插件完全可以记录与管理（解释权下放），不违反任何规则；
- **结算面——在系统外**：法币分红、股权交易走银行与现实法律程序，Spark 从不替法币结算，系统内的账只是影子；
- **权力面——内核经济对象封死，插件数据是组织自选**：**内核经济对象（积分 / 债权）永远不得作为票权输入**（三底线，结构封死）；而插件里的资本数据（如股权）能否作为票权权重，是**组织自己的治理选择**——治理策略可引用插件按契约发布的快照（见 [governance](../affairs/governance.md)），Spark 不替组织选择治理形态。三底线封死的从来不是资本本身，而是**内核经济对象的资本化通道**。

## 合规边界

- **合法形态**：封闭的成员内部记账 + 登记经营 + 依法纳税 + 不可分割储备的合作社 / 社会企业；
- **红线形态**：积分面向不特定公众可兑换、可流通、形成行情，或承担准货币支付职能——触碰非法金融 / 支付清算 / 代币监管红线；
- Spark **不为任何组织提供面向公众的资金清算结算服务**：清算只发生在签约组织之间的账面记录，**不过手法币、不设资金池**；
- **积分不是法定工资**：成员与组织应按合作社社员关系设计，避免被认定为事实劳动关系；法定社保、最低工资等义务仍以法币履行，积分不得替代；
- **涉税**：对外经营依法纳税；组织间以资源 / 服务平仓在税法上可能被"视同销售"，内部互助的税务口径在落地前须取得专业意见——[存证链](../foundation/evidence.md)恰好提供完整凭证留存。

## 边界（这一篇不做什么）

- 不隔离、不禁止法币，也不追求发行平行货币替代法币；
- 不提供任何法币通道、资金池、公众清算或对私兑现；
- 不替组织做税务 / 法律认定，只提供完整、可核验的留痕。
