# 第四层 · 经济（Economy）：让 W—G—W 可运行

> 状态：定稿
>
> 完整单页母稿：项目根目录《共同体经济系统设计.md》v0.10（**原地保留**）；本层是它的结构化拆分，内容口径以母稿为准。

## 一句话

Spark 经济系统是一套"**联合生产关系的可运行预制件**"：

- **组织内部**：贡献经集体评定记为积分，成员凭积分领取组织资源、兑付即销毁——数字形态的劳动凭证；
- **组织之间**：以双边受理协议组成网络，成员只用本组织积分就能在签约组织消费，组织间记账、定期以**真实资源**平仓——去资本化的互助清算；
- **对外部世界**：组织可以用法币正常经营，但法币不得反过来成为积分的价值尺度，经营盈余用于扩大互惠板块，而非资本积累。

它不消灭交换、不消灭货币（法币可正常使用），它消灭的是**货币作为资本的运动**。

## 最高验收判据：允许 W—G—W，禁止 G—W—G′

沿用《资本论》对两种流通的区分，作为本系统**最高判据**：

- **W—G—W（为买而卖，允许）**：生产 / 贡献 → 凭证 / 货币 → 换取使用价值，流通以需求满足为终点，媒介被花掉、退出；
- **G—W—G′（为卖而买、自行增殖，禁止）**：以钱生钱、雇佣占有剩余、按资分配、食利抽租。

> **任何一条新规则上线前只问一句：它让 G—W—G′ 更容易启动，还是更困难？** 更容易的否决，更困难或中性的放行。

## 三条不可变底线

与事务层"公示延迟禁令"同级，任何组织策略都不得覆盖：

1. **不设积分与法币的对私双向兑换**——个人不得用积分向组织或他人兑现法币；
2. **不计息、不杠杆、不派生**——积分与组织往来余额不得生息、存贷或作为本金增殖；
3. **经济差异买不到治理权力**——积分、净债权、出资都不得转化为票权、组织控制力或规则豁免。

## 效力三层：内核强制什么、组织自定什么、社区推荐什么

总原则是"**机制与政策分离**"——内核只提供机制，不内置任何分配意识形态：

| 层 | 内容 | 谁定 | 性质 |
| --- | --- | --- | --- |
| 宪章层（不变量） | 唯一序列与防伪、状态机不可回退、销毁见证、发行恒等式、**发行必须依据经事务决议授权的发行策略**（策略立改废走决议；策略内发行内核按规则确定性执行；裁量发行逐次决议）、无私钥直接发行接口、规则公开义务、票权不可买、无对私兑现 | **内核强制，组织无权关闭** | 程序性运行前提，不是分配立场——不接受可以不使用 Spark |
| 政策层（组织立法） | 积分性质、发行依据与评定方法、储备比例、兑付目录、汇率公式、平仓周期、净应收额度、治理者报酬倍数 | **组织自定**，写入开源规则并公开 | 一切实质价值判断都在这一层 |
| 模板层（社区经验） | 时间银行型、定额计件型、集体评议型、家庭型等规则包样本 | 社区发布、组织显式选用或改写 | 非默认、无权威，**不存在隐式默认值** |

"Spark 不做价值判断"的准确含义：框架在"怎样分配才公平"的各种善观念之间保持中立，把实质判断让渡给自愿共同体；但中立不等于价值真空——它退守到一层**最薄的程序性价值**（透明、可核验、自愿、可退出、防伪、决议授权），如同操作系统的内存保护，是任何应用安全运行的前提，而非对某个应用的立场。

## 内核边界：唯一正确答案判据与三种手段

**判据：只有存在"唯一正确答案"、可由密码学或确定性计算判定的事才归内核；凡需要理解内容、判断意图、权衡价值的事，内核最多提供透明证据，决定权在组织、插件或成员。**

| 手段 | 含义 | 例子 |
| --- | --- | --- |
| 结构性强制 | 不设接口、物理上做不到，且无需理解内容 | 无对私兑现 / 计息 / 存贷接口；协议无 fee 字段；票权模块不读积分余额；状态机不可回退 |
| 证据性支持 | 确定性地产出指标 / 告警 / 存证，任何节点复算一致，但**不裁决** | 在外 / 可兑比值、净额头寸、汇率偏离、健康度、锁定超时率 |
| 不介入 | 纯治理与社会过程，内核无对应机制 | 是否雇佣、贡献值多少、资源真伪、定价经营、授信与平仓决定、争议裁决 |

**内核明确不做**（非穷举）：

- **不做争议仲裁**——只有"挂起 / 锁定，直到收到该组织公开规则认可的裁决凭证"这一状态原语；谁来裁、怎么裁、裁决结果，全归组织程序或插件；
- 不评定贡献价值、不核验资源真伪、不定价，不管生产 / 库存 / 档期 / 目录；
- 不评价规则优劣、不为任何组织背书，不替组织做签约 / 授信 / 平仓 / 出清的实质决定。

> **设计自检三问（任何新功能先过）**：它有唯一正确答案吗？没有就只能做证据。它需要理解内容吗？需要就不归内核。它在替组织做价值选择吗？是就删掉。

## 与其他层的接口

- **发行策略的立改废、红冲、授信、协议签署**的授权都来自[事务层](../affairs/governance.md)经公示延迟的决议；策略内的发行由内核按规则确定性执行（触发事件须来自存证链 / 事务日志的可验证记录），策略外的裁量发行逐次走决议；经济层不接受任何绕过事务的私钥直接指令；
- "怎么计分、什么资格、兑付什么"是第四类解释对象——**经济规则包插件**，必须开源、由组织选用（见[插件层](../plugins/README.md)）；
- 复用底座：[记名身份](../foundation/identity.md)、[链式存证与离线核验](../foundation/evidence.md)、[跨组织网关信封](../foundation/network.md)。
