# 愿景：让自由人联合体成为可以安装的现实

> 状态：定稿 ｜ 顶层分册
>
> 本篇讲我们**为什么出发、要走到哪里**。产品由什么构成看 [产品全景](product-map.md)，一步一步怎么走看 [路线图](roadmap.md)。

## 一、我们面对的母题：协作本身正在被私有化

工业时代，资本占有工厂与机器这些生产资料。数字时代，被占有的是更底层的东西——人们**如何联合、如何沟通、如何彼此取信、如何分配共同成果**的那套协作基础设施，连同数据和"规则的定义权"，一起被收进了少数平台。

这不只是"数据存在别人服务器上"这么简单：

- 谁算合格成员、什么是一次有效决议、贡献值多少、成果怎么分——**解释权在平台**，群体只能接受；
- 平台成了数字时代的"组织者"，而真正在劳动、在协作的人，沦为平台上的流量与资源；
- 于是今天，任何一个想"自己把自己组织起来"的群体——一个小区、一个合作社、一个开源社区、一群劳动者——都不得不先**租用**某个平台的秩序，并接受它随时可以收回。

**人类联合起来做事的能力本身，被出租了。** Spark 想把它赎回来，交还给每一个自愿结合的人。

## 二、我们相信什么

1. **协作与联合的能力，应当像语言一样属于每个人**，而不是被某家公司占有的一项收费服务；
2. **一个群体内部的规则，应当由这个群体自己定义、自己可见、自己可改**——谁合格、怎么决策、贡献怎么算，不能由千里之外的黑箱替它决定（这就是"定义权去中心化、解释权下放给组织"）；
3. **生产可以为需求而组织，而不必一律为资本增殖而组织。** 数字世界早已由开源给出证据：人们不靠雇佣、不靠股权，也能联合生产出世界级的东西。缺的从来不是"人性是否可能"的证据，而是一套让这种关系在**日常协作与分配**里也能跑起来的基础设施。

## 三、终局：自由人联合体的数字基础设施

我们要做的不是又一个更好用的办公软件，而是——

> **把"另一种生产关系"做成可安装、可复制、可验证、且无人能私有的预制件。**

它让一个群体可以：

- **物归其主**：数据与共同生产的记录属于参与者自己，没有谁能关机、删库、坐地收租；
- **自愿结合而不产生层级权力**：人们自下而上结成共同体，可加入、可退出、可层层联合，但上级不会因为层级就获得对下级的支配权；
- **可验证地决策与行动**：一切组织效力来自公开的集体决策，任何单个密钥、单个管理者都无法专断；
- **按劳动领取、互助交换**：贡献被记为兑付即销毁的劳动凭证，共同体之间相互受理、以真实产出平仓，而不是用钱生钱。

它是一个清醒的**过渡装置**：一端诚实地连着今天的货币与市场（不隔离法币、合法经营、依法纳税），另一端通向"各尽所能、按劳分配"的关系。它不幻想一夜之间取代市场，而是让"为使用价值而联合"的板块，一块一块地长大。

> **衡量它的，不是消灭了多少货币，而是：有多少劳动、多少生产、多少生活，不再被迫服从资本增殖的逻辑；人们为了生存而不得不向资本出卖自己的比例，是否在持续下降。**

当这样的共同体从家庭、小区、合作社出发，沿递归网络生长到成千上万，它们以互助清算相连、以公开存证取信、以可替换的客户端与规则保有自由——这张网本身，就是一种**不依赖任何中心、也无人能够收购**的新型公共基础设施。这是我们愿意用很多年去逼近的图景。

## 四、Spark 在其中是什么

Spark 是上述生产关系的"运行时"：一个无中心服务器的**协作与共同体操作系统**，由四层（[物](foundation/README.md) → [人](community/README.md) → [事](affairs/README.md) → [价值](economy/README.md)）和一条把解释权下放给组织的正交轴（[插件](plugins/README.md)）构成，全景见 [product-map.md](product-map.md)。

它的关键不在于功能多，而在于**边界即立场**：内核只保留"存在唯一正确答案"的机制，把一切价值判断通过开源插件交还给组织。它不替任何人回答"什么是公平"，但保证：**无论你选择什么，它都透明、可核验、可退出，且无法被任何人偷偷篡改。**

## 五、清醒：宏大不等于许诺

正因为目标远大，才更不能在地基上撒谎。我们明确知道自己做不到什么：

- **不假装一套软件就能更替社会生产关系**——那需要软件之外的社会条件；Spark 只负责把"另一种关系"做到真的能用、能被验证、能被复制（理论坐标与自觉边界见 [capital-defense](economy/capital-defense.md)）；
- **不做公链 / 加密货币 / 匿名支付 / 内容裁判 / 托管式 SaaS**——不做全局共识、不发币、积分不与法币对私兑现、不做中心化审核与仲裁、也不提供"我们替你保管"的云（见各分册非目标）；
- **不做救世主、不设总指挥部**：没有哪家公司在背后规划一切，它本身就是去中心化开发、任何人都可分叉与继承的公共品；
- **每一条"系统保证"都标明成色**：哪些是内核物理封死的、哪些只是让坏事藏不住、哪些只能靠共同体自己治理——三档分得清清楚楚，绝不把治理问题伪装成技术承诺。

## 六、道路：再远的愿景，也从最小的真实共同体起步

宏大不等于四处铺开。生产关系无法在 PPT 里被验证，只能在一个一个**真实的小共同体**里被检验。

- **先自举**：用 Spark 开发、发布、分发 Spark 自身——自己先活在自己主张的关系里，缺陷按天暴露；
- **第一站是业委会 + 街道办**：它足够小，却完整压中全部四层；更关键的是，它的结果必须被**系统之外**的现实机构，仅凭一个离线核验工具就接受——这是"无人持有的协作，也能被现实世界信任"的第一块硬证据（见 [foundation/evidence](foundation/evidence.md)）；
- 从一个叶节点跑通，再沿递归共同体复制到楼栋、小区、街道、跨区域网络。

**路是一步一步走的，但要保证每一步都朝着第三节的方向。** 阶段划分见 [roadmap.md](roadmap.md)。

## 七、为谁而做

- **近处**：一个想把票投明白、把公共账看清楚的业主；一个想自证清白的业委会；一个要核验结果的街道办；
- **中间**：一切自愿联合的共同体——合作社、社区与行业组织、开源社区、对数据与规则主权有要求的团队和个人；
- **远处**：每一个不愿把"联合起来的能力"租给平台、愿意为使用价值而非资本增殖去劳动的人。

也要诚实：期待"厂商全托管、零责任、强管控"的团队，这套东西并不适合——**主权与责任从来是一体两面**：它把主权还给参与者，也把"照看自己节点、保管好自己身份密钥"的责任交回给参与者。

## 八、成功的尺度

- **近期，可判定**：Spark 完整运行在 Spark 上；一个真实业委会的一次真实投票，被街道办凭独立核验工具接受——先证明"这条路走得通"；
- **远期，看方向**：有多少真实的生产与生活在这套关系里运转；互惠板块相对外部资本板块的自足度是否在增长；是否真有一些人，因此少出卖了一份被迫的劳动。

我们这一代人未必能亲眼走到终局。但要确保自己铺下的每一块砖，都**朝向**它。
