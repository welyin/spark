# 存证：发生过的事，可以被独立证明

> 状态：定稿 ｜ 分册：第一层 · 底座
>
> 上游实现：`wiki/architecture/sync/evidence-anchoring-export.md`、`wiki/architecture/sync/sync-and-evidence.md`、`docs/protocol/foundation/sync-evidence.md`

## 一句话

每个节点在本地把"发生过的改动"串成一条**只增不改**的密码学链；组织成员再把各自的链头承诺**锚定**到同一个默克尔根；任何一段记录都能导出成一个自包含文件——**核验方不用装 Spark、不用联网、甚至不是本组织成员，都能独立验证它没被篡改、且当时确实处在组织的共同状态里。**

## 为什么存证是底座，而不是某个业务插件

投票、公共账本、决议、档案用印……所有治理类功能都需要同一件事："事后能证明这条记录当时就是这样、没被改过"。

- 这件事**有唯一正确答案**（哈希对不对、签名真不真、链连不连得上），所以属于内核；
- 而"这条记录在业务上意味着什么、算不算数"没有唯一答案，归插件 / 组织（解释权下放，见 [../plugins](../plugins/README.md)）；
- 存证底座**不以投票等任何插件为前提**，治理插件只是它的第一批消费者。

## 三层结构

1. **本地存证链**：本机每一处被纳管的改动按确定顺序上链，只增不改、环环相扣——改动任意一条，其后所有哈希都会对不上；
2. **跨成员锚定**：每个成员定期、或在治理事件发生时声明"我本地链头是这个承诺"；任一成员可把全员的链头承诺压缩成**一个组织级默克尔根**，再用一条"包含证明"证明"我的链头确实在这个共同状态之内"；
3. **分叉可举证、但不裁决**：若同一节点出现链头回退、或同一序号对应不同内容，就会留下两份并排的签名证据。系统**检测并告警、拒绝采纳可疑锚，但不替你判定谁对谁错**——这是"不做拜占庭共识"既定决策下的诚实边界：**能证明有人作伪，裁决权仍归组织治理层**（见 [../affairs/governance.md](../affairs/governance.md)）。

## 导出包：一份能拿到线下的证据

- **自包含单文件**：链段 + 链头 + 全员锚记录 + 默克尔根 + 包含证明 + 规格说明 + 导出者签名，核验所需材料全部在内；
- 可按业务范围收窄（如只导出某次投票的选票集合），也可全量导出；
- **可打印**，适配街道办、物业这类线下提交、归档场景。

## 独立核验：不装 Spark、不联网

提供一个独立核验程序（单一可执行文件），依次完成：验导出者签名 → 逐条重算哈希并校验链连续 → 验每个锚签名、重算默克尔根并校验包含证明 → 核对声明范围 → 输出人读报告与"通过 / 失败（指明原因）"结论。

**分层诚实——它能证明到哪一层，就只说到哪一层：**

- **第一层 · 完整性**：外部核验方即使**完全不知道成员名单**，也能验证"密码学完整性、签名有效、内容未被篡改"；
- **第二层 · 成员**：导出包可附**成员名册存证快照**（已拍板前置到里程碑二前，见 open-questions Q05），附快照后核验方可进一步验证"签名者当时确为组织成员"；
- **第三层 · 业务资格**："签名者当时有没有某项资格"（如是不是业主）纯密码学与名册都回答不了，需验证人签发的资格凭证佐证。工具会明确标注自己验证到了哪一层、哪一层未覆盖，而不是含糊地给出"全部属实"。

## 隐私边界

- 锚记录与链头**只含哈希和节点标识、不含内容**，成员间锚定交换不泄露数据本身；
- 对外导出是**显式动作**，导出范围由成员 / 组织按规则发起，不存在自动外发。

## 边界（这一层不做什么）

- 不做共识裁决、不做链上治理判定：**只证明，不判对错**；
- 不做公共存证墙、不依赖外部区块链 / 第三方时间戳服务，也没有权威墙钟——时间取自本地并在核验时如实呈现，不盲信任何单一时间源；
- 个人域暂不做跨设备锚定（自有设备间一致性由[个人同步](personal-data.md)保证，锚定的价值场景在组织治理）。
