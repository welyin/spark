## 贯穿这一层的三条产品原则

1. **加入不是吞并，层级不产生权力。** 结构用来表达隔离：下级加入上级后，自身数据边界原样不动，上级不自动获得下级内部的任何权力；上级影响下级的唯一通道是"承认 / 撤销承认"与共同体决议的既定效力。
2. **隔离由结构表达，密码学只负责证明。** 成员边界、保密边界靠"域"这一结构来划，不靠域内再做一套加密；密码学用于签名、存证、传输保密。需要隔离，就拆成子组织，而不是在一个组织里做密码学子群。
3. **平台不做政治判断。** 凡"谁有资格"（门槛、履历、业主 / 居民身份、资格组合）一律不出现在内核，只能由组织规则 / 插件给出；内核只保证**门槛可验证、执行确定、过程透明**。

## 与上下层的接口

- **向下**：复用底座的身份派生（每入一个域派生一个不可关联的域身份）、个人 / 组织两条同步通道、P2P 与网关暂存、链式存证；
- **向上**：为第三层事务提供"可以被决议改变的成员结构"——事务的决议能改组、创设、撤换一个组织，前提是该组织**事先声明**了效力来源。
